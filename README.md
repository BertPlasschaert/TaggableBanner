# Taggable Banner

This code allows users to add their usernames to the repo banner.
Inspired by the way [timburgan](https://github.com/timburgan) creatively used github actions
to update his chess README.MD. I wanted to flair up my own homepage by creating some kind of
guestbook. Give it a try [here](https://github.com/BertPlasschaert)!

## How does it work?

When the visitor clicks the link below the banner and creates the issue using the pre-filled values, a github action will start to run.
This action will interact with the python code in this repo and execute the following steps.

- Check in the `README.MD` file if the user has already added their tag.
  - If the tag already exists, communicate it using a comment under the issue and close it.
- Add the username to the `README.MD` and add the tag to the `banner.svg`
- Communicate this to the user using a comment under the issue and close it

The banner is an **.svg** file which is generated by the file `banner.py` file.
The SVG is ideal for this as its scales perfectly for every screen. It is also
a fairly nice interface to progamatically generate.

## Test it locally

The python script has two cli commands:
```
python3 -m python.taggablebanner.cli check "<username>"
python3 -m python.taggablebanner.cli add "<username>"
```
> ! make sure the **python** folder has been added to the `PYTHONPATH`

Use these two commands to test the code locally.
The github actions call the same commands when an issue is opened.

## How to make it your own

The title: `hello` is a string value you can easily change.
Nothing except the bricks, cracks and splats are on-file svg elements.
The bulk of your work will be to update the 'magic numbers' that position these elements.
I've implemented exclusion zones around the brick elements and title so no tags are able to spawn over them.
So if you change these elements make sure to update accourdingly.
Addings fonts is possible but you'll need to encode them using [this method](https://blog.frankel.ch/fonts-embedded-svg/) and create a config for them.
